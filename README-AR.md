# Quero AI — دليل التشغيل والنشر المبسّط

هذا مشروع موقع عربي متجاوب باسم **Quero AI** بألوان بنفسجية وبيضاء.

## ماذا يفعل؟
- يعرض صفحة رئيسية عربية.
- يفتح منصة Quero في تبويب منفصل.
- يسمح بلصق نص السؤال والحصول على شرح تعليمي من الذكاء الاصطناعي.
- لا يطلب اسم مستخدم أو كلمة مرور منصة Quero.
- لا يتصل بحساب Quero ولا يرسل إجابات إلى المنصة.

## مهم قبل النشر
لا يوجد في المشروع تكامل مباشر مع منصة Quero. رابط المنصة أعاد رفض الوصول الآلي (403) أثناء الفحص، ولم يتوفر توثيق API رسمي. لذلك يفتح الموقع المنصة فقط، ويستخدم الطالب نسخ نص السؤال ولصقه في Quero AI. لا تدخل بيانات حسابك في هذا الموقع.

## نشر الموقع على الإنترنت (Render)

1. حمّل ملف ZIP وفك الضغط عنه على جهازك.
2. أنشئ حسابًا في GitHub، ثم أنشئ مستودعًا جديدًا (Repository).
3. ارفع جميع ملفات هذا المجلد إلى المستودع.
4. أنشئ حسابًا في Render واربطه بحساب GitHub.
5. من Render اختر **New +** ثم **Blueprint**، واختر المستودع الذي رفعت إليه الملفات.
6. سيقرأ Render ملف `render.yaml` ويجهز خدمة الموقع. وافق على الإنشاء.
7. من إعدادات الخدمة في Render افتح **Environment** وأضف:
   - `OPENAI_API_KEY` = مفتاح API الخاص بك من مزود الذكاء الاصطناعي.
   - `OPENAI_MODEL` = `gpt-4o-mini` (أو نموذج متاح لحسابك).
8. احفظ الإعدادات وانتظر انتهاء النشر. سيعطيك Render رابطًا ينتهي بـ `onrender.com`.

قد تتغير أسماء الأزرار في Render. وقد تتطلب خدمة الذكاء الاصطناعي رصيدًا أو فوترة منفصلة. لا تشارك مفتاح API مع أي شخص ولا تضعه داخل ملفات `public`.

## تشغيله على جهازك (اختياري)
يتطلب Node.js إصدار 18 أو أحدث.

1. افتح مجلد المشروع في الطرفية.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى ملف اسمه `.env`.
4. ضع مفتاح API في `OPENAI_API_KEY` داخل `.env`.
5. نفّذ `npm start`.
6. افتح `http://localhost:3000`.

## حماية البيانات
- لا تحفظ كلمات مرور منصة Quero في هذا الموقع.
- لا ترفع ملف `.env` إلى GitHub.
- لا تضع مفاتيح API في كود المتصفح.
- لا تلصق معلومات شخصية أو بيانات حسابات في مربع السؤال.

## الملفات
- `server.js`: الخادم وطلب الذكاء الاصطناعي.
- `public/`: واجهة الموقع.
- `.env.example`: مثال إعدادات سرية.
- `render.yaml`: إعداد نشر Render.
